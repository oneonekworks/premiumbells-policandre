Use

Homepage headline · service page H1 (Policandre, Clopote, Iconostase) · a project page’s category word. Only where the word names the material.

Size

Cormorant 500–600 at 40 px or more. Below that the sheen turns muddy: use the -solid token or ink.

Budget

One phrase per screen. Never on section titles, buttons, body, cards or dark panels (a light set for dark grounds can follow if needed).

Partner

Pair it with the teal italic line. Warm metal above, cool patina below: the same gold–teal contrast the palette is built on.

Link state

Underline is a 3 px bar in the word’s -line token, drawn as a pseudo-element (a real text-decoration gets filled by the gradient). Focus: gold ring.

Fallback
