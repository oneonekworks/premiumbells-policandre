# Integrating v5.10 into rbells_policandre

Read this before `cms-sanity.md`: the repo (Next 16, Tailwind 4, Sanity, Phase 7 schema) already has most of what the design needs. `cms-sanity.md` was written for a generic CMS; where it differs, **this file wins**. Existing decisions in `docs/` stay in force unless listed here (prices check, singletons, field-level translation, `next/font`, Webpack dev).

## 1 · Tokens → `app/globals.css`

Merge the `@theme` block and the `@layer components` recipes from `tokens/tokens.css` into `app/globals.css` (don't `@import "tailwindcss"` twice). Keep fonts on `next/font` (self-hosted, `latin-ext`), not the Google `<link>` used in the reference HTML.

Rename / replace the current tokens (`docs/design-foundations.md`):

## 2 · `homePage` singleton — section order and fields

New fixed order (each keeps `enabled`): **hero → services (+ catalogues) → works → about → audio → blog (+ testimonial) → footer offer**. The Phase 7 order (catalogues/testimonial before audio, about last) changes.

| Section | Keep | Add / change |
|---|---|---|
| `hero` | `badge` {label, link} = the "Nou" pill · `tagline` = italic claim · `primaryCta` "Vezi lucrările" · `secondaryCta` "Cereți o ofertă" | **`slices`** (exactly 3) {`service` → service, `image` imageWithMetadata (optional; falls back to the service `coverImage`), `line` localeString ≤ 48}. **`figures`** (≤ 3) {`value` number, `label` localeString} — the user asked for 60 · 3 · 12 (overrides decision 4 for this strip only); `value` may later be computed from projects. `title` + `highlight` become the single headline (the three words are rendered from the slices' service titles; keep `title` as an editable override). `image` → optional (share image only). `lead` unused. |
| `services` | `heading` "Serviciile noastre" · `services[]` | Replace `eyebrow` + `intro` with **`groups`** (3) {`title` localeString, `facts` short block content (bold only, ≤ 3 lines), `services[]` → service}. Card name = service `title`, card photo = `coverImage`, hover hint = `cardLabel`. |
| `catalogues` | lists published `catalogDownload`s | Drop `intro`. Render as the compact card: name link opens `file.asset.url` in a new tab ("Citiți online →"), round button downloads (`?dl=` param). |
| `works` (new) | — | `heading` "Lucrările noastre", `items[]` (9–12 gallery images from projects; empty = latest featured), chips from `workCategory` counts, map tile from project locations. |
| `about` | `heading`, `video` (poster required ✓) | Replace `body` with **`lead`** (block content, bold marks) + **`points`** (≤ 3) {`key` localeString, `text` localeString}. **`statement`** → testimonial (reuse the type: quote, name, role, portrait 3:2, `context` = fact line) for Denis Latisev; add `shortQuote` (≤ 200) to testimonial or store the shortened quote in `quote` and keep the full one on the Despre noi page. `cta` stays optional and is left empty (no link in the design). |
| `audio` | → audioFeature (title, context, audio, artwork, durationSeconds) | Drop `eyebrow`. Add **`waveform`** number[100] to `audioFeature`, generated by a script at import/upload, never in the browser. |
| `blog` | `heading` "Din jurnal", `posts[]` (empty = 3 newest) | Cards use `excerpt` (≤ 170 chars), category/type, derived reading time; no author on cards. |
| `testimonial` | → testimonial | Rendered inside the blog section (above the posts, heading becomes "Mărturie și jurnal") only when set; hidden by default. |
